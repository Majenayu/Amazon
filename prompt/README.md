# Prompts Log

This folder stores every prompt I (the user) give to Kiro, along with Kiro's response.

Each conversation is saved as a numbered markdown file so I have a full record of the work
done for the Amazon ML Challenge.

## Index

- `01-connect-repo.md` — Connect the workspace to the GitHub repo and push a README
- `02-explain-task.md` — Asked Kiro to explain its task in simple words
- `03-red-team-plan.md` — Adversarial review (defect report) of my Amazon ML Challenge plan
- `03-red-team-full-prompt.txt` — The complete raw prompt I used for that red-team review
  (kept as plain text; the duplicate copies were removed during cleanup)
- `04-store-prompts-and-explain.md` — Set up this prompt folder and a plain-English explanation
